# VizMix インストール手順（買い切り版）

VizMix はアプリに**署名（有料の開発元証明）を付けていない**ため、初回起動時に OS の
警告が出ます。これは正常です。下記の手順で問題なく起動できます。
（※今後、署名付きの版に差し替え予定です）

ダウンロードした OS のセクションだけを読んでください。

---

## 🍎 Mac（Apple Silicon / Intel 共通）

ダウンロードした `VizMix-1.0.0-universal.dmg` を使います。
このファイルは **M1/M2/M3/M4（Apple Silicon）と Intel Mac の両方**で動作します。

1. `VizMix-1.0.0-universal.dmg` をダブルクリックして開く
2. 表示された **VizMix のアイコンを「アプリケーション」フォルダにドラッグ**
3. 「アプリケーション」フォルダの **VizMix を右クリック（または Control を押しながらクリック）→「開く」** を選ぶ
   - ⚠️ 普通にダブルクリックすると「開発元を確認できないため開けません」と出て開けません。**必ず初回だけ「右クリック →開く」**してください
4. 「開いてもよろしいですか？」と聞かれたら **「開く」** を押す

これで起動します。2 回目以降は普通にダブルクリックで開けます。

### それでも「壊れているため開けません」と出る場合

ダウンロード時に macOS が付ける検疫マークが原因です。**ターミナル**を開いて次の 1 行を
実行してください（VizMix をアプリケーションフォルダに入れた後）:

```
xattr -cr /Applications/VizMix.app
```

実行後、もう一度「右クリック →開く」してください。

## 🪟 Windows（64bit）

### インストーラ版（おすすめ）: `VizMix Setup 1.0.0.exe`

1. `VizMix Setup 1.0.0.exe` をダブルクリック
2. 「**Windows によって PC が保護されました**」という青い画面が出たら
   **「詳細情報」** をクリック
3. 下に現れた **「実行」** ボタンを押す
4. あとは画面に従ってインストール（インストール先は変更できます）

### インストール不要版（ポータブル）: `VizMix-1.0.0-win.zip`

1. zip を右クリック →「すべて展開」
2. 展開したフォルダの中の **`VizMix.exe`** をダブルクリック
3. 同じく「Windows によって PC が保護されました」が出たら **「詳細情報」→「実行」**

> SmartScreen の警告は「署名を付けていない」ことが理由で、ウイルスではありません。

## 🐧 Linux（64bit / AppImage）

ダウンロードするファイル: `VizMix-1.0.0.AppImage`

1. ファイルに実行権限を付ける（ファイルマネージャのプロパティ →「実行可能」にチェック、
   またはターミナルで）:
   ```
   chmod +x VizMix-1.0.0.AppImage
   ```
2. ダブルクリック、またはターミナルで実行:
   ```
   ./VizMix-1.0.0.AppImage
   ```

### 起動しない場合（FUSE エラー）

古い AppImage 形式の実行に `libfuse2` が必要です。Ubuntu の場合:

```
sudo apt install libfuse2
```

それでも動かない時は、展開して直接起動できます:

```
./VizMix-1.0.0.AppImage --appimage-extract
./squashfs-root/vizmix
```

## 動作要件（全 OS 共通）

- **WebGL2 対応の GPU**（VJ 用途では専用 GPU 推奨。GTX 1060 / RX 580 以上が快適）
- 動画素材はご自身で読み込みます（アプリには同梱の小さなサンプルのみ）
